# Генератор фракталов и рекурсивных алгоритмов
Приложение представляет собой интерактивную программную систему для визуализации геометрических фракталов и классических рекурсивных алгоритмов. Программа разработана на платформе **WPF (.NET)** с использованием прямого рендеринга графики в растровый буфер через **`WriteableBitmap`**, что обеспечивает высокую производительность и плавность анимации.

## Основные возможности

* **Набор алгоритмов**:
1. **Треугольник Серпинского** — классический геометрический фрактал.
2. **Кривая Гильберта** — пространственно-заполняющая кривая.
3. **Ханойская башня** — демонстрация алгоритма с покадровой анимацией перемещения дисков (поддерживает рекурсивный метод и итеративный подход через явный стек).
4. **Кривая Леви** — фрактальная кривая на основе равнобедренных прямоугольных треугольников.
5. **Фрактал Вичека** — симметричный крестообразный фрактал.

* **Двухпроходный замер времени**:
* *Проход 1*: Фоновый расчет алгоритма «на чистой скорости» с фиксацией времени выполнения рекурсии с помощью `Stopwatch` без задержек интерфейса.
* *Проход 2*: Плавная покадровая визуализация процесса для демонстрации пользователю.


## Пользовательский интерфейс
* **Панель управления (верху)**:
* Выпадающий список выбора алгоритма (`ComboBox`).
* Регулятор глубины рекурсии / количества дисков (`N`) в аккуратной рамке.
* Чекбокс активации итеративного решения через стек (доступен для Ханойской башни).
* Регулятор задержки кадров анимации в рамке со строгими прямыми углами (`CornerRadius = 0`).
* Кнопки управления **«Запустить»** и **«Стоп»**.
* **Холст визуализации (`Canvas` + `Image`)**:
* Область вывода графики с поддержкой масштабирования и фильтрации ближайшего соседа (`NearestNeighbor`).
* **Информационная строка (внизу)**:
* Отображает актуальный статус выполнения и точное время расчета рекурсии (сохраняет значение при изменении масштаба).


## Системные требования
* Платформа: .NET 8.0 (или выше) / WPF
* Среда разработки: Visual Studio 2022/2026
